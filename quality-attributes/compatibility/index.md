# Compatibility

Compatibility describes the degree to which a system can exchange information with other systems and perform its functions while sharing an environment and resources.

## Sub-characteristics

| Sub-characteristic | Definition |
|---|---|
| [Co-existence](co-existence.md) | The system can perform its functions without negatively impacting other systems sharing the same environment |
| [Interoperability](interoperability.md) | Two or more systems can exchange information and use the information that has been exchanged |
