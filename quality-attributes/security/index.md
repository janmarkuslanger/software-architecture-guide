# Security

Security describes the degree to which a system protects information and data so that persons or other systems have the degree of data access appropriate to their types and levels of authorisation, and to defend against attack patterns by malicious actors.

## Sub-characteristics

| Sub-characteristic | Definition |
|---|---|
| [Confidentiality](confidentiality.md) | Data is accessible only to those authorised to access it |
| [Integrity](integrity.md) | The system prevents unauthorised access to or modification of data or programs |
| [Non-repudiation](non-repudiation.md) | Actions or events can be proved to have taken place and cannot be repudiated |
| [Accountability](accountability.md) | Actions of an entity can be traced uniquely to that entity |
| [Authenticity](authenticity.md) | The identity of a subject or resource can be proved to be the one claimed |
