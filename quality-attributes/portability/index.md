# Portability

Portability describes the degree to which a system or component can be transferred from one hardware, software, or other operational or usage environment to another.

## Sub-characteristics

| Sub-characteristic | Definition |
|---|---|
| [Adaptability](adaptability.md) | The system can be adapted for different or evolving environments without requiring changes beyond those specified |
| [Installability](installability.md) | The system can be successfully installed or uninstalled in a specified environment |
| [Replaceability](replaceability.md) | The system can be replaced by another product for the same purpose in the same environment |
