# Usability

Usability describes the degree to which a system can be used by specified users to achieve specified goals with effectiveness, efficiency, and satisfaction in a specified context of use. It applies equally to end-user interfaces and developer-facing surfaces such as APIs, CLIs, and SDKs.

## Sub-characteristics

| Sub-characteristic | Definition |
|---|---|
| [Appropriateness Recognisability](appropriateness-recognisability.md) | Users can recognise whether the system is appropriate for their needs |
| [Learnability](learnability.md) | Users can learn to use the system effectively with specified effort |
| [Operability](operability.md) | The system has attributes that make it easy to operate and control |
| [User Error Protection](user-error-protection.md) | The system protects users against making errors |
| [User Interface Aesthetics](user-interface-aesthetics.md) | The interface enables pleasing and satisfying interaction |
| [Accessibility](accessibility.md) | The system can be used by people with the widest range of characteristics and capabilities |
