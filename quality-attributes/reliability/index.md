# Reliability

Reliability describes the degree to which a system performs specified functions under specified conditions for a specified period of time. It covers how often faults occur, whether the system continues operating despite faults, how quickly it returns to a correct state after failure, and how long it remains operational without failure.

## Sub-characteristics

| Sub-characteristic | Definition |
|---|---|
| [Maturity](maturity.md) | The system meets reliability needs under normal operation; low defect escape rate |
| [Availability](availability.md) | The system is operational and accessible when required for use |
| [Fault Tolerance](fault-tolerance.md) | The system operates as intended despite the presence of hardware or software faults |
| [Recoverability](recoverability.md) | The system can recover data and re-establish its desired state after failure |
